# NhanBDS

Website thương hiệu cá nhân cho **Mai Hoàng Nhân BĐS**, xây dựng bằng React và Vite.

## Chạy dự án

```bash
npm install
npm run dev
```

- Website: `http://localhost:5173/`
- Trang quản trị mẫu: `http://localhost:5173/admin`

## Build

```bash
npm run build
```

## Công nghệ

- React
- Vite
- Lucide React
- CSS responsive
